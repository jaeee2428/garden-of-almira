# Heliconia — *Heliconia*

lobster claw, false bird-of-paradise · Heliconiaceae

| | |
|---|---|
| Scent | none |
| Bayong order | 11 of 18 |
| Colour on the card | `#e0261a` |

**What it looks like (the model follows this):** Banana-like clump; long paddle leaves; upright or hanging zigzag stems of stiff boat-shaped red bracts edged yellow-green.

**Card text:** The red-and-yellow “claws” are boat-shaped bracts; the true flowers are small and hide inside them. A garden ornamental in the tropics, grown for its flowers and for cutting; I found no Visayan medicinal use recorded for it.

Sources: StuartXchange (Philippine medicinal plants), PTKDL
