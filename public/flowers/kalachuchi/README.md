# Kalachuchi — *Plumeria rubra*

frangipani, temple tree · also: kalatsutsi · Apocynaceae (dogbane family)

| | |
|---|---|
| Scent | sweet, strongest at night |
| Bayong order | 3 of 18 |
| Colour on the card | `#fff2d8` |

**What it looks like (the model follows this):** Small tree with thick, blunt, forking grey branches; long leathery leaves clustered at the branch tips; waxy 5-petalled pinwheel flowers, white with a yellow centre (or pink/red), in loose clusters.

**Card text:** The frangipani, often planted in churchyards and cemeteries. In folk use the bark decoction is held on the gums for toothache and the milky sap, mixed with coconut oil, is rubbed on rheumatic joints; the leaves are poulticed on bruises and scabies. The sap irritates skin and the plant is toxic if eaten.

Sources: StuartXchange (Philippine medicinal plants), PTKDL
