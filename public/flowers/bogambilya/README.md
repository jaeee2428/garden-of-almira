# Bogambilya — *Bougainvillea*

bougainvillea, paper flower · also: bombi, bugambilya · Nyctaginaceae (four-o’clock family)

| | |
|---|---|
| Scent | none |
| Bayong order | 6 of 18 |
| Colour on the card | `#d1186a` |

**What it looks like (the model follows this):** Thorny woody climber; heart-shaped leaves; papery coloured bracts in threes, each holding one tiny cream tubular flower.

**Card text:** The bright “petals” are bracts around three tiny cream flowers; thorny stems climb arches and walls across the Visayas. Elsewhere (Mexico) the flowers are steeped as a tea for cough, but I did not find a documented Visayan medicinal use.

Sources: StuartXchange (Philippine medicinal plants), PTKDL
